# LandingPageModelo

Modelo de landing page em português para cafeterias e docerias, com identidade fictícia Casa Miga.

## Recursos

- Layout responsivo para celular, tablet e desktop.
- Cardápio com filtros por categoria.
- Menu para celular.
- Seções de apresentação e encomendas.
- Botões para WhatsApp com mensagem pronta.

## Visualização

Abra `index.html` no navegador. Não requer instalação de dependências ou etapa de build.

## Personalização

- Edite textos, produtos e preços em `index.html`.
- Ajuste cores e estilos em `style.css`.
- Configure `WHATSAPP_NUMBER` em `script.js` com código do país e DDD, somente dígitos. Atualize também os links de WhatsApp e a indicação de contato em `index.html` para funcionamento sem JavaScript.
- O número **+55 (11) 00000-0000** é fictício e não recebe pedidos. Substitua-o por um número válido antes de usar comercialmente.
- Marca, cardápio e valores são ilustrativos.

## Imagens e fontes

Fotografias do Unsplash, armazenadas em `assets/`. Fontes DM Sans e Playfair Display carregadas pelo Google Fonts; esse carregamento requer acesso à internet.
